# LEGO Трекер

Трекер деталей LEGO, где каждая запись — фиксированная структура `(id, name, color), поэтому она хранится в `tuple, так как такая структура обеспечивает неизменяемость по смыслу и хешируемость данных.
Все записи лежат в `list` — это меняющийся упорядоченный набор, где важен порядок добавления и удобен линейный проход при поиске по цвету.
Для быстрого поиска по `id` используется `dict` (O(1) по хешируемому неизменяемому ключу `int`), а `set` применяется для гарантии уникальности `id`. Для хранения цветов используется enum лист.
Код избегает ловушек семинара: нет mutable default arguments (все аргументы явные), нет алиасов, так как методы `all_colors`/`all_ids`/`find_by_color` возвращают копии, а не ссылки на внутренние структуры, и `list` нигде не используется в качестве ключа.
